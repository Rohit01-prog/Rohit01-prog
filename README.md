**Hi there, I'm Rohit! 👋
I'm a developer who genuinely enjoys turning ideas into working software. Most of my days are spent building web platforms, experimenting with applied AI, and solving problems that make everyday life a little easier.
Right now, I'm working on CityFix Bihar, a civic grievance platform built with Supabase to streamline community issue reporting, and Dr. MediScan, an AI health assistant leveraging LangChain and Mistral. I also built a real-time Gesture Steering Simulator using OpenCV and MediaPipe, which won 1st Prize at the AWS Student Chapter Prompt-2-Pixel competition.
Beyond writing code, I love diving deep into system workflows, connecting backend services to clean user interfaces, and learning how modern AI agents can automate complex tasks. When I'm not debugging or testing APIs, you'll probably find me exploring new tech stacks or discussing product ideas.
Always open to collaborating on meaningful projects or talking tech.**
